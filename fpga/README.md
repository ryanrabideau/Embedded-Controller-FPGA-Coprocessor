# FPGA

RTL and verification files for the Lattice iCE40 FPGA co-processor.

The FPGA is intended to perform deterministic, timing-critical data capture and buffering that can be offloaded from the STM32.

This directory will contain:

- SystemVerilog RTL
- Testbenches
- Timing and pin constraints
- Simulation results
- FPGA build scripts
